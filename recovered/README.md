# MindTune EEG, FocusCalm and Adaptive Mantra Recovery

This directory preserves the recovered MindTune EEG and adaptive-protocol implementation.

It includes:

- FocusCalm FC-11 acquisition code;
- FC-11 capture pipeline;
- BrainLab EEG analysis;
- EEG and BrainLab tests;
- adaptive mantra and closed-loop components;
- cognitive-state and adaptation-policy components;
- technical documentation and validation reports.

## Legal and data boundaries

This recovery intentionally excludes:

- APK and XAPK files;
- vendor native libraries;
- proprietary machine-learning models;
- decompiled vendor source code;
- personal EEG recordings;
- experimental session datasets;
- database files;
- binary reverse-engineering fixtures.

Only original MindTune code and publishable technical documentation should remain.

## Status

The recovered material must be audited and migrated into the canonical package structure before it is considered production-ready.
