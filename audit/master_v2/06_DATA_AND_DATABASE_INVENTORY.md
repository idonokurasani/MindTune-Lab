## 4. Data Contracts

- `mpe/events.py`: canonical `Event` envelope with `event_id`, `event_type`, `session_sequence_number`, `provenance`, `payload`.
- `docs/specification/v1.1/EVENT_STORE_SPEC.md`: append-only, monotonic sequence, optimistic concurrency.
- `docs/specification/v1.1/PERSISTENCE_BOUNDARIES.md`: classifies objects as persistent, derived, cached, ephemeral, stream-only.
- `docs/specification/v1.1/DATABASE_SCHEMA_SPEC.md`: entity/field constraints (spec only, no runtime DB code).

## 5. Data Ownership

- **Authoritative:** `EventStore` is the source of truth for protocol sessions.
- **Derived:** `RuntimeState`, `Outcome`, trial/block summaries.
- **External/cached:** `ContentItem` from domain adapters, `RenderedStimulus` media handles, TTS cache.
- **Sensitive:** raw EEG CSV, `Observation` payloads with audio, `CapturedResponse` with voice samples — must be encrypted at rest per `PERSISTENCE_BOUNDARIES.md`.
